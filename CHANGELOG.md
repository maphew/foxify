# Changelog

All notable changes to the Foxify project will be documented in this file.

## [1.0.0] - 2025-07-25

### Added
- Support for Node.js 18+ and npm 9+
- Modernized build system with Webpack 5
- Comprehensive test suite with Jest
- Improved error handling and validation
- Updated documentation with detailed setup instructions
- CI/CD configuration (GitHub Actions)
- Security best practices implementation

### Changed
- Upgraded all dependencies to their latest stable versions
- Replaced deprecated `request` library with `axios`
- Migrated from `node-sass` to `sass` (Dart Sass)
- Updated Webpack configuration for better performance
- Improved code organization and structure
- Enhanced error messages and logging

### Fixed
- Security vulnerabilities in development dependencies
- Compatibility issues with modern Node.js versions
- Build and packaging issues
- Various bug fixes and performance improvements

### Removed
- Deprecated and unused dependencies
- Outdated build scripts and configurations

## [0.1.0] - 2018-01-01

### Added
- Initial release of Foxify
- Basic Chrome to Firefox extension conversion
- Web interface for easy conversion
- Support for CRX, ZIP, and XPI formats
